DECISION 1 (2026-03-18):
  Topic: Data path structure
  Decision: Changed LOCAL_BASE from data/ to lake/
  Reason: Pre-created data/ directories had locked Windows ACLs
  Impact: All 12 pipeline paths now use lake/ prefix

DECISION 2 (2026-03-18):
  Topic: Write mode for raw Parquet data
  Decision: Use mode("append") with clear_directory_contents() instead of
            mode("overwrite")
  Reason: Spark's overwrite mode tries to delete output dir via FileUtil
          which fails on locked Windows directories
  Impact: Only affects 01_generate_data.py (Parquet writes)
          Delta writes (bronze/silver/gold) use overwrite fine

DECISION 3 (2026-03-18):
  Topic: Python worker fix
  Decision: Set PYSPARK_PYTHON = sys.executable in spark_config.py
  Reason: Windows App Execution Aliases redirect 'python' to Microsoft Store
  Impact: All scripts importing spark_config.py automatically get this fix

  Topic: Section 13 implementation
