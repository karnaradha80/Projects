## nxzen Brand Design Applied

### Colour Palette
| Token | Hex | Used for |
|---|---|---|
| Black | `#000000` | Sidebar bg, output box bg, download buttons, multiselect tags |
| Dark grey | `#111111` | Sidebar secondary elements (select boxes, inputs) |
| Mid grey | `#222222` | Hover states, borders |
| Green accent | `#5EE340` | Primary buttons, active tab underline, progress bar, left accent borders, sidebar right border |
| Off-white | `#F5F7FA` | Main content bg, metric cards, tab bar |
| Border grey | `#DDE3EC` | Dividers, card borders, expanders |

### Styled Elements
| Element | Style applied |
|---|---|
| Sidebar | Black bg, green right border (`3px solid #5EE340`), white/light text |
| Primary buttons | Green fill `#5EE340`, black text, bold, rounded 6px |
| Secondary buttons | White fill, black border, green border on hover |
| Download buttons | Black fill, white text, dark grey hover |
| Tabs | Light grey bar, green underline on active tab |
| Metrics | White card, green left accent border (4px) |
| Output box | Black bg, green left border (4px), monospace light text |
| Alerts | Colour-coded left borders (green=success, dark=info, amber=warning, red=error) |
| Progress bar | Green fill |
| File uploader | Dashed border, turns green on hover |
| Expanders | Green hover on header text |
| Multiselect tags | Black bg, white text |
| Checkboxes | Green accent |
| Input focus | Green border + green glow shadow |

**Source reference:** https://www.nxzen.com/ (dark professional theme + lime green brand accent from logo)
