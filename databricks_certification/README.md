# Databricks Certified Data Engineer Professional — Study Guide

## Exam Overview
- **Exam**: Databricks Certified Data Engineer Professional
- **Duration**: 120 minutes
- **Questions**: ~60 questions (multiple choice)
- **Passing Score**: ~70%
- **Format**: Proctored online exam

## Exam Domain Weights

| Domain | Weight |
|--------|--------|
| Databricks Tooling | ~20% |
| Data Processing | ~30% |
| Data Modeling | ~20% |
| Security & Governance | ~10% |
| Monitoring & Logging | ~10% |
| Testing & Deployment | ~10% |
