# Phase 0 — Python Basics
**Duration:** 2 weeks | **Exam:** None (prerequisite phase)

## Goal
Build enough Python to write PySpark code confidently.
Your C# background means syntax is the only gap — logic transfers directly.

## Folder Structure
```
Phase0_Python_Basics/
├── notes/
│   ├── week1_syntax_and_collections.md   ← Variables, lists, dicts, loops, functions
│   └── week2_oop_pandas_basics.md        ← Classes, Pandas, list comprehensions
├── practice/
│   └── exercises.md                      ← Coding exercises to practice
└── cheat_sheet.md                        ← Python vs C# quick reference
```

## Week-by-Week Plan
| Week | Topics | Gate |
|------|--------|------|
| Week 1 | Syntax, data types, collections, loops, functions, lambda | Write a script that filters and aggregates a list |
| Week 2 | Classes, Pandas DataFrame, list comprehensions, exceptions | Read CSV, filter rows, output summary |
